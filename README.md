# ixb-ports

把一份 Clash 订阅里的每个节点，变成一个只在本机监听的 SOCKS5 端口。ixBrowser 里一条代理对应一个端口。

不修改系统代理，不占用原来的 Clash 端口（例如 `7892`）。只有主动连接这些端口的程序才会走到对应节点。

## 环境

- Node.js 18 或更新版本
- [mihomo](https://github.com/MetaCubeX/mihomo)。macOS 可执行 `brew install mihomo`。也可用环境变量 `MIHOMO_BIN` 指向二进制文件。

## 启动

```bash
npm install
npm start
```

浏览器打开 http://127.0.0.1:8787 ，贴上 Clash 订阅链接，点「拉取并启动」。

点「复制」得到的是 `127.0.0.1:42001` 这种文本，不是 `socks5://` 开头的网址。ixBrowser 的添加框按冒号拆字段，带协议头会把主机和端口填错。

在 ixBrowser 里这样填：

- 代理类型：SOCKS5
- 把 `127.0.0.1:42001` 粘进添加框，或手填主机 `127.0.0.1`、端口 `42001`
- 账号、密码留空
- 使用系统代理：不使用

服务要一直开着。关掉进程后这些端口会停。再次拉取时，同一个节点仍使用原来的端口。

## 端口

| 端口 | 用途 |
| --- | --- |
| `8787` | 本机页面。可用 `IXB_PORT` 改 |
| `19091` | 这一份 mihomo 的控制接口，只监听 `127.0.0.1` |
| `42001` 起 | 每个节点一个 SOCKS5。当前有多少节点，就连续占用多少个 |

订阅链接、节点密码和生成的配置都在 `data/`。这个目录已忽略，不要提交，也不要发给别人。
